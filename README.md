# Finance Bros website (React + React-Bootstrap + Vite)

    npm install
    npm run dev            # local development
    npm run build          # production build for hosting → dist/
    npm run build:single   # one self-contained HTML file → dist/index.html

Runs in DEMO mode (browser storage) until Supabase keys are added to `.env`.
Full step-by-step launch instructions: see **DEPLOY.md**.
